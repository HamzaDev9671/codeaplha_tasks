# Task 1 - CGPA Calculator

A CGPA Calculator developed in C++ as part of my CodeAlpha Internship.

## Features

- Calculate SGPA based on course grades and credit hours
- Calculate credit-weighted CGPA
- Supports multiple semesters
- Validates grades, GPA, credit hours, and number of courses
- Displays results with two decimal places

## Technologies Used

- C++
- Object-Oriented Programming
- Vector
- Input validation
